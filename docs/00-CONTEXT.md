## 최종 선정 기획

**장보고 (JangBogo) — 대한민국 가맹점을 위한 에이전트 커머스 게이트웨이**

> "상품 목록만 붙여넣으면, 5분 만에 당신의 가게가 AI 에이전트에게 물건을 파는
> 헤드리스 머천트(x402 결제 엔드포인트)가 됩니다."

- 판매자 측: 가맹점 → x402 결제 가능한 API 상점 + A2A 견적 응답 에이전트 자동 생성
- 신뢰 레이어: 들어오는 구매 에이전트의 **AP2 mandate(서명된 위임장)를 가맹점이 검증** —
  한도 초과/서명 불일치/범위 밖 구매는 결제 자체를 거절 (가맹점 관점의 AML·신뢰 통제)
- 구매자 측(데모): 예산 한도 내에서 사람 승인 없이 견적 비교→선택→x402 USDC 결제하는 자율 조달 에이전트
- 정산: USDC 수취 → 원화 정산 시뮬레이션 대시보드 (VAN/PG 오프램프 스토리)

이름: 장보고 = 신라 해상 무역왕(상거래 인프라의 상징) + "장 보고 올게"(에이전트가 대신 장을 봄) 이중 의미.

## 왜 이 기획인가 — 리서치 대응 매트릭스

| 리서치 발견 | 장보고의 대응 |
|---|---|
| 심사 위시리스트 ① 실동작 온체인 결제 | devnet 실트랜잭션 + 익스플로러 링크를 대시보드에 상시 노출 |
| ② 사람 승인 없는 자율 결제(정책·예산 한도 내) | AP2 mandate 예산 + 결정론적 정책 엔진. 단 집행 주체를 **판매자 측**에 둔 것이 차별점 |
| ③ Solana 결제 스택 실전 활용 | x402(HTTP 402 플로우) + devnet USDC(mock 발행, 운영진 공식 권장) + pay.sh 호환 설계 |
| ④ 직관적 UX + 왜 온체인인가 | 토스급 온보딩 UX 목표. 당위성: 에이전트는 카드를 못 씀(3DS·본인인증) + 해외 결제 수수료 3.5%→$0.0001 + 차지백 없음 + 즉시 정산 |
| 경쟁 제출작 6팀 전원이 '구매자측 한도 집행'에 집중 | **판매자측(가맹점 온보딩+검증)은 공백**. 수상 패턴 #2 '기존 커머스의 에이전트 어댑터'가 "이 해커톤 단일 트랙에 가장 정합적"으로 분석됨 |
| 전략 공백: AP2+A2A+x402 3-프로토콜 풀데모 희소 | 한 데모에서 mandate 발급(AP2) → 견적 교환(A2A 메시지 구조) → x402 온체인 정산까지 관통 |
| 심사단 5개 기관의 관심 축 | KSNET(33만 가맹점 솔라나페이 실험+AML 통제) · KG이니시스(가맹점 온보딩·K-콘텐츠 해외결제 56%) · 신한카드(하이브리드 결제) · 더즌(원화 정산) — 전부 '가맹점을 어떻게 새 결제 레일에 태우나'의 문제 |
| 국내 수상 코드(KAIA 해커톤): 규제 양립 스토리 + 토스급 UX | mandate 검증 = 가맹점 KYC/AML 훅 스토리 + 원화 정산 시뮬레이션 + 한국어 온보딩 UX |
| 학술 논거: 프롬프트 인젝션 완전 방어 불가 → 결정론적 한도 집행이 해법 (arXiv 논거 체인 6-1) | 정책 엔진은 LLM 판단이 아닌 결정론적 검증. LLM(Gemini)은 상품 매칭·사유 생성에만 사용 |
| PPT 필수: 수익모델 | 거래 수수료 0.5% + 정산 리포트 SaaS + (확장) 선정산 팩토링 수수료 |

## 버린 대안과 이유

1. **구매자측 한도 지갑** (mandate-vault·policy_pay류) — 경쟁 최다 밀집 구역. 탈락.
2. **프랜차이즈 식자재 조달** — solply가 선점. 탈락.
3. **구매팀 에이전트(견적·에스크로)** — buydesk가 선점. 탈락.
4. **K-콘텐츠 티켓 자동구매** — 스캘핑(매크로 티켓팅) 규제 리스크가 심사장에서 역풍 가능. 탈락.
5. **선정산(팩토링) 에이전트** — KG파이낸셜 신사업과 정합적이나 데모 복잡도 과다. **장보고의 확장 로드맵**으로 흡수.

## 심사 커뮤니케이션 포지셔닝

- Four Pillars 프레임 기준 **T3(완전 자율, 서브센트·M2M)로 가는 관문을 T2(규칙 위임) 안전장치로 여는 제품**이라고 명시적으로 규정.
- 데모데이 원라이너: "33만 가맹점이 코드 한 줄 없이 에이전트 경제의 판매자가 됩니다."
- 확인 불가 사항 정직 고지 원칙 유지(리서치 문서 관례 준수).
